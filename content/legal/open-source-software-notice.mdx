# Open Source Software Notice

## 1. Purpose and Scope

Graphical Playground ("GP", "we", or "the Project") incorporates third-party open source software
("OSS") components across its engine, web platform, and supporting cloud infrastructure. This Open
Source Software Notice (the "Notice") is provided in satisfaction of the attribution, notice, and
disclosure obligations imposed by the licenses governing those components.

Nothing in this Notice modifies, waives, or supersedes the terms of any license under which a
component is distributed. Where this Notice and the original license text conflict, the original
license text governs. Full license texts for each identified license family are publicly available
at links referenced below and, for permissive licenses reproduced by reference, at
https://opensource.org/licenses.

This Notice does not itself grant any rights to any person in respect of Graphical Playground's own
source code, trademarks, or other proprietary assets, which remain governed by Graphical Playground's
own [Terms of Service](https://graphical-playground/legal/terms-of-service) and licensing
documentation.

## 2. How this Notice is Organized

Because Graphical Playground is composed of functionally distinct systems maintained on different
release cadences, this Notice is organized by system rather than as a single flat list:

- [Section A](#section-a-engine): Engine: the native C++23
  [`gp-engine`](https://github.com/GraphicalPlayground/gp-engine) core (rendering, platform
  abstraction, tooling).
- [Section B](#section-b-platform): Platform: the web application, curriculum delivery platform,
  and admin/back-office tooling ([`gp-platform`](https://github.com/GraphicalPlayground/gp-platform)).
- [Section C](#section-c-cloud-devops-&-infrastructure): Cloud, DevOps & Infrastructure: hosting,
  orchestration, observability, and infrastructure-as-code tooling used to build, ship, and operate
  GP ([`gp-infrastructure`](https://github.com/GraphicalPlayground/gp-infrastructure)).
- [Section D](#section-d-third-party-services): Third-Party Services: proprietary, non-OSS services
  that GP depends on operationally, disclosed here for transparency even though no OSS license
  notice obligation attaches to them.

Within each section, components are listed alphabetically with their license family, copyright
notice, and a link to the authoritative project source. Versions are indicative of what is currently
in use and should be reconciled against the live dependency manifests before each publication of
this Notice.

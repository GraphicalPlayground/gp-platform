# CHANGELOG ([@gp](https://github.com/GraphicalPlayground)/fonts)

## v0.0.2

### Additions

- Added [`MonaSans`](https://github.com/github/mona-sans) font to the package.
- Added [`MonaSansMono`](https://github.com/github/mona-sans) font to the package.
- Added [`HubotSans`](https://github.com/github/hubot-sans) font to the package.
- Created the `fonts.css` file to import all fonts in one place.
  - Added `--font-mona-sans` CSS variable for the `MonaSans` font.
  - Added `--font-mona-sans-mono` CSS variable for the `MonaSansMono` font.
  - Added `--font-hubot-sans` CSS variable for the `HubotSans` font.

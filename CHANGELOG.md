# CHANGELOG ([@gp-platform](https://github.com/GraphicalPlayground/gp-platform))

## v0.0.2

### Additions

- Added a new `@gp/fonts` package to manage fonts for the platform.
- Added the new `@gp/ui` package to manage UI components for the platform.
- Added a new `@gp/backend` application for the backend of the platform.

### Changes

- Separated the `@gp/web` packages into `@gp/admin`, `@gp/marketing` and `@gp/app` packages to allow for more flexibility in the future.

### Removals

- Removed the old fork of [`HeroUI`](https://heroui.com/) from the platform to be using a customized [`@primer`](https://github.com/primer) package instead.
